GetWord(int, Func<int, TItem, bool>, out bool)

Tries to read the word at index index, which can be a span of items verified by itemKindPredicate (if the starting index is verified by itemKindPredicate) or a span of content not verified by itemKindPredicate (if the starting index does not point to anything verified by itemKindPredicate).

TItem[] GetWord(int index, Func<int, TItem, bool> itemKindPredicate, out bool isItemKind)

Parameters

index int

The index at which the word starts.

itemKindPredicate Func<int, TItem, bool>

A predicate that verifies if the first item in the selected range serves as the delimiter (the predicate returns true if so). For example, if the predicate verifies ,, then the current word if the buffer is My awesome buffer, isn't it cool? starting from index, is My awesome buffer. If the predicate verifies ;, then the current word if the buffer is ;;so very awesome starting from index, is ;;.

isItemKind bool

True if the array is fully comprised of the item kind verified by itemKindPredicate. If False, no items verified by itemKindPredicate is present.

Returns

TItem[]

The line, as an array of items.
