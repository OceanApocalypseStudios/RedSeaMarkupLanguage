TryGetWord(int, Func<int, TItem, bool>, Span<TItem>, out bool, out int)

Tries to read the word at index index, which can be a span of items verified by itemKindPredicate (if the starting index is verified by itemKindPredicate) or a span of content not verified by itemKindPredicate (if the starting index does not point to anything verified by itemKindPredicate).

bool TryGetWord(int index, Func<int, TItem, bool> itemKindPredicate, Span<TItem> destination, out bool isItemKind, out int itemCount)

Parameters

index int

The index at which the word starts.

itemKindPredicate Func<int, TItem, bool>

A predicate that verifies if the first item in the selected range serves as the delimiter (the predicate returns true if so). For example, if the predicate verifies ,, then the current word if the buffer is My awesome buffer, isn't it cool? starting from index, is My awesome buffer. If the predicate verifies ;, then the current word if the buffer is ;;so very awesome starting from index, is ;;.

destination Span<TItem>

The span which will be the destination for the read content.

isItemKind bool

True if the span is fully comprised of the item kind verified by itemKindPredicate. If False, no items verified by itemKindPredicate is present.

itemCount int

The amount of characters that were written to destination.

Returns

bool

False if the buffer is out of bounds, the reading was only partial or an exception occured.

Remarks

This method may lead to partial reading (for example if destination is not large enough). When this happens, the return value will be False but itemCount will be set to something greater than 0.
